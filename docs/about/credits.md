## Versioning

Releases are named by date, `YYYY.MM.DD`, with `+1`, `+2` and so on for a second release the same
day, and the jar is `LDEncore-1.12.2-<version>.jar`. Every release's notes name the upstream
Theatrical release the port is based on.
